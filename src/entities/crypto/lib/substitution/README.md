# Документация: Блочный шифр подстановки

## 1. Теоретический базис
Алгоритм разбивает входной текст на блоки фиксированной длины m символов. Для множества всех возможных блоков генерируется случайная взаимно однозначная таблица замен (подстановок) на основе алфавита V

* **Алфавит (V):** Набор разрешенных символов (в текущей конфигурации: `"012"`)
* **Размер блока (m):** Количество символов в одном блоке (в текущей конфигурации: `3`)
* **Мощность пространства блоков:** Количество возможных комбинаций составляет |V|^m. Для алфавита `"012"` и блока `3` генерируется ровно 3^3=27 вариантов подстановок (от `000` до `222`)

## 2. API Класса `SubstitutionCipher`

Класс инкапсулирует в себе состояние таблиц шифрования и методы преобразования строк

### Конструктор
```typescript
new SubstitutionCipher(alphabet: string, blockSize: number, padSymbol?: string)
```
* `alphabet`: Строка, содержащая уникальные символы алфавита
* `blockSize`: Число, задающее длину блока m
* `padSymbol`: (Опционально) Символ для дополнения последней группы, если текст не кратен размеру блока. По умолчанию `'0'`

### Публичные методы

#### `encrypt(plainText: string): string`
Принимает открытый текст, дополняет его до кратности размера блока символом `padSymbol`, разбивает на блоки по m символов и заменяет каждый блок согласно таблице `encryptMap`.
* **Исключения:** Выбрасывает `Error`, если блок содержит символы, не входящие в сгенерированное пространство комбинаций алфавита

#### `decrypt(cipherText: string): string`
Принимает шифрограмму, разбивает её на блоки по m символов и восстанавливает исходный текст с помощью обратной таблицы `decryptMap`
* **Исключения:** Выбрасывает `Error`, если встретился неизвестный зашифрованный блок

### Внутренние методы

#### `generateAllCombinations(alphabetRunes: string[], length: number, current: string, result: string[]): void`
Рекурсивный метод, реализующий алгоритм размещения с повторениями. Формирует полный базис возможных блоков данных
* **Принцип работы:** На каждом шаге рекурсии метод берет текущую строку `current` и поочередно прибавляет к ней каждый символ из массива `alphabetRunes`. Как только длина строки `current` достигает целевого размера блока `length` (m), строка фиксируется и добавляется в результирующий массив `result`

#### `generateTables(): void`
Метод отвечает за построение криптографического алфавита подстановок
* **Принцип работы:** 
  1. Вызывает `generateAllCombinations` для получения эталонного списка исходных блоков (комбинаций)
  2. Создает копию этого списка и перемешивает её случайным образом с помощью эффективного алгоритма **Тасования Фишера - Йетса**. Это гарантирует случайность и уникальность распределения
  3. Проходит по обоим спискам синхронно и связывает исходный блок с перемешанным, заполняя две карты: `encryptMap` (для прямого шифрования) и `decryptMap` (для обратного декодирования)
* **Свойства биекции:** Поскольку массивы состоят из уникальных элементов и имеют одинаковую длину, маппинг гарантированно получается взаимно однозначным. Любой сгенерированный блок зашифруется и расшифруется без потерь и коллизий


## 3. Пример работы алгоритма

При инициализации `new SubstitutionCipher("012", 3, "0")` внутреннее состояние таблиц генерируется случайным образом (пример биекции):

```text
Входной блок (x) | Выходной блок Cv(x)
------------------------------------
000              | 102
001              | 221
...              | ...
222              | 011
```

### Процесс шифрования текста `0121`:
1. **Препроцессинг (Padding):** Длина строки `0121` равна 4. Она не кратна размеру блока `3`. Строка дополняется символом `0` до длины 6 → `012100`
2. **Разбиение на блоки:** Строка разделяется на два блока: `[012]` и `[100]`
3. **Подстановка:** Каждый блок заменяется по таблице:
   * `012` -> (например) `201`
   * `100` -> (например) `002`
4. **Результат:** `201002`.
