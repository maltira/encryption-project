# Блочный шифр подстановки

## 1. Теория
Алгоритм разбивает входной текст на блоки длины `m`. Для множества всех возможных блоков генерируется случайная взаимно однозначная таблица замен (подстановок) на основе алфавита V.

* **Алфавит (V):** Набор разрешенных символов (`012`)
* **Размер блока (m):** Количество символов в одном блоке (`3`)
* **Мощность пространства блоков:** Количество возможных комбинаций составляет |V|^m. Для алфавита `"012"` и блока `3` генерируется ровно 3^3=27 вариантов подстановок (от `000` до `222`)

## 2. API Класса `SubstitutionCipher`

### Публичные методы

#### `encrypt(plainText: string, key: number | string): string`
Принимает открытый текст и ключ, строит таблицы подстановки по ключу, дополняет текст до кратности размера блока символом `padSymbol`, разбивает на блоки по m символов и заменяет каждый блок согласно таблице `encryptMap`

* **Требования:** текст должен состоять только из символов алфавита, а ключ быть целым неотрицательным числом

#### `decrypt(cipherText: string, key: number | string): string`
Принимает шифрограмму и ключ, строит те же таблицы подстановки, разбивает шифрограмму на блоки по m символов и восстанавливает исходный текст с помощью обратной таблицы `decryptMap`

* **Исключения:** Выбрасывает `Error`, если длина шифрограммы не кратна размеру блока

### Внутренние методы

#### `generateAllCombinations(current: string, result: string[]): void`
Метод, формирущий всевозможные блоки текста длинной m  из алфавита V

* **Принцип работы:** На каждом шаге рекурсии метод берет текущую строку `current` и поочередно прибавляет к ней каждый символ из алфавита. Как только длина строки `current` достигает размера блока, строка фиксируется и добавляется в массив `result`

#### `generateTables(key: number): void`
Метод отвечает за построение криптографического алфавита подстановок

* **Принцип работы:** 
  1. Вызывает `generateAllCombinations` для получения всевозможных блоков
  2. Создает копию этого списка и перемешивает её псевдослучайным образом с помощью ключа `key`
  3. Проходит по обоим спискам и связывает исходный блок с перемешанным, заполняя две карты: `encryptMap` (для шифрования) и `decryptMap` (для дешифрования)


## 3. Пример работы алгоритма

В зависимости от ключа `key` генерируется биекция, например:

```text
Входной блок (x) | Выходной блок Cv(x)
------------------------------------
000              | 102
001              | 221
...              | ...
222              | 011
```

### Процесс шифрования текста `0121`:
1. **Padding:** Длина строки `0121` равна 4. Она не кратна размеру блока `3`. Строка дополняется символом `0` до длины 6 -> `012100`
2. **Разбиение на блоки:** Строка разделяется на два блока: `[012]` и `[100]`
3. **Подстановка:** Каждый блок заменяется по таблице:
   * `012` -> (например) `201`
   * `100` -> (например) `002`
4. **Результат:** `201002`
