# Документация: Алгоритм DES в режиме ECB

## Общий алгоритм

1. **Разбиение на блоки:** Сообщение делят на равные блоки размером ровно 64 бита (8 байт), так как таков размер блока базового алгоритма DES
2. **Дополнение (Padding):** Если длина исходных данных не делится на 64 бита нацело, последний блок дополняют специальными битами до нужного размера
3. **Независимое шифрование:** Каждый 64-битный блок открытого текста $OT_i$ преобразуется функцией шифрования DES с ключом K в блок шифротекста $C_i$
$$C_i = DES(OT_i, K)$$
4. **Расшифрование:** Каждый блок шифротекста $C_i$ обрабатывается функцией обратного преобразования DES с тем же ключом K: 
$$OT_i = DES(C_i, K)$$

## Полный пошаговый алгоритм функции шифрования DES

Алгоритм DES принимает на вход **64-битный блок открытого текста** и **64-битный ключ** (из которых реально используются **56 бит**), а на выходе возвращает **64-битный блок шифротекста**. В основе лежит 16-раундовая сеть Фейстеля.

---

### Шаг 1. Предварительная обработка ключа (Key Schedule)

Исходный 64-битный ключ преобразуется в 16 раундовых ключей по 48 бит каждый.

1. **Перестановка с выбором 1 (PC-1):** Из исходного 64-битного ключа удаляется каждый 8-й бит (8, 16, ..., 64) — они используются как биты четности. Остальные 56 бит перемешиваются по таблице `PC-1` и делятся на две половины по 28 бит: $C_0$ и $D_0$.
2. **Циклический сдвиг:** Для каждого раунда $i$ (от 1 до 16) половины $C_{i-1}$ и $D_{i-1}$ циклически сдвигаются **влево** на определенное количество бит (на 1 бит в раундах 1, 2, 9, 16; на 2 бита во всех остальных). Получаются пары $C_i$ и $D_i$.
3. **Перестановка с выбором 2 (PC-2):** Пара $C_i$ и $D_i$ объединяется в 56-битный блок, который пропускается через таблицу `PC-2`. На выходе выбираются и перемешиваются **48 бит**. Это и есть раундовый ключ $K_i$. Процесс повторяется для всех 16 раундов.

---

### Шаг 2. Начальная перестановка данных (IP)

1. Входной 64-битный блок открытого текста проходит через таблицу начальной перестановки **IP (Initial Permutation)**, где биты жестко меняются местами.
2. Результат делится ровно пополам на два 32-битных блока:
   * $L_0$ — левые 32 бита;
   * $R_0$ — правые 32 бита.

---

### Шаг 3. 16 раундов Сети Фейстеля

Данные проходят через 16 циклов вычислений. Для каждого раунда $i$ (от 1 до 16) расчет идет по формулам:
* $L_i = R_{i-1}$
* $R_i = L_{i-1} \oplus f(R_{i-1}, K_i)$

#### Внутренний алгоритм функции раунда $f(R_{i-1}, K_i)$:
Функция принимает 32 бита данных $R_{i-1}$ и 48 бит ключа $K_i$, выдавая на выходе 32 бита:

1. **Расширение:** 32-битный блок $R_{i-1}$ расширяется до **48 бит** по специальной таблице, где 16 определенных битов дублируются
2. **Сложение с ключом:** Полученные 48 бит складываются по модулю 2 со сделанным ранее 48-битным раундовым ключом $K_i$
3. **S-блоки (S-boxes, подстановка):** 
   * Результат XOR (48 бит) делится на 8 последовательных групп по 6 бит в каждой
   * Каждая 6-битная группа отправляется в свой персональный S-блок (от $S_1$ до $S_8$)
   * Внутри S-блока первый и последний бит 6-битного числа определяют номер строки таблицы (от 0 до 3), а средние 4 бита — номер столбца (от 0 до 15)
   * Число на пересечении строки и столбца преобразуется в **4 бита** на выходе
   * Все 8 выходов по 4 бита объединяются обратно в один **32-битный блок**
4. **Перестановка (P-box):** Полученные 32 бита перемешиваются по фиксированной таблице перестановки $P$. Это финальный результат работы функции $f$

После завершения функции $f$ её результат складывается по модулю 2 с $L_{i-1}$, формируя $R_i$. Процесс переходит к следующему раунду

---

### Шаг 4. Финальное объединение и перестановка ($IP^{-1}$)

1. После окончания 16-го раунда получаются блоки $L_{16}$ и $R_{16}$.
2. Они меняются местами и объединяются в один 64-битный блок в порядке: **$R_{16}$ в начале, $L_{16}$ в конце** (это необходимо для симметрии алгоритма при дешифровании)
3. Полученный 64-битный блок проходит через финальную таблицу перестановки **$IP^{-1}$ (Inverse Initial Permutation)**, которая является обратной для самой первой таблицы IP из Шага 2

**Выходной результат:** 64-битный блок готового шифротекста.
