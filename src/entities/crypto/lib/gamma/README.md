# Документация: Шифрование гаммированием

## 1. Теоретический базис
Алгоритм гаммирования заключается в наложении псевдослучайной последовательности чисел (гаммы) на числовые коды символов открытого текста по модулю размера используемого алфавита $B = 256$ (расширенная таблица ASCII)

Псевдослучайная гамма формируется с помощью **линейного конгруэнтного генератора (ЛКГ)** (один из самых простых способов получать псевдослучайные числа, где каждое следующее число вычисляется из предыдущего) по формуле:
$$T_{i+1} = (A \cdot T_i + C) \pmod B$$

* **Алфавит (V):** Расширенная таблица ASCII (коды символов от `0` до `255`)
* **Мощность |V|:** `256`
* **Множитель (A):** `9`
* **Приращение (C):** `49`
* **Начальное значение (T0):** `24` (стартовое состояние генератора)

### Формулы преобразования:
* **Шифрование:** $C_i = (x_i + k_i) \pmod B$
* **Дешифрование:** $P_i = (y_i - k_i + B) \pmod B$

где $x_i$ - числовой код открытого символа, $y_i$ - числовой код зашифрованного символа, $k_i$ - соответствующий элемент гаммы

---

## 2. API Класса `GammaCipher`

`alphabet`: все символы с кодами `0..255`

### Публичные методы

#### `encrypt(plainText: string): string`
Генерирует гамму длины текста и посимвольно вычисляет шифротекст: `cipherCode = (char.charCodeAt(0) + gamma[i]) % B`, после чего код переводится обратно в символ через `String.fromCharCode`

#### `decrypt(cipherText: string): string`
Генерирует ту же гамму заданной длины и восстанавливает открытый текст: `plainCode = (char.charCodeAt(0) - gamma[i] + B) % B`

### Внутренние методы

#### `generateGamma(length: number): number[]`
Генерирует массив псевдослучайных чисел заданной длины `length`

* **Принцип работы:** На каждом шаге вычисляет следующее псевдослучайное число по формуле ЛКГ `(A * current + C) % B` и обновляет текущее состояние `current`

---

## 3. Пример работы алгоритма

При параметрах $A = 9$, $C = 49$, $T_0 = 24$, $B = 256$ генератор формирует следующую гамму:

* $k_0 = (9 \cdot 24 + 49) \pmod{256} = 265 \pmod{256} = 9$
* $k_1 = (9 \cdot 9 + 49) \pmod{256} = 130 \pmod{256} = 130$
* $k_2 = (9 \cdot 130 + 49) \pmod{256} = 1219 \pmod{256} = 195$

### Процесс шифрования текста `"ABC"`:
Коды символов: `'A' = 65`, `'B' = 66`, `'C' = 67`.

1. **Генерация гаммы:** `[9, 130, 195]`
2. **Сложение по модулю 256:**
   * $C_0 = (65 + 9) \pmod{256} = 74$ -> символ `'J'`
   * $C_1 = (66 + 130) \pmod{256} = 196$ -> символ с кодом `196`
   * $C_2 = (67 + 195) \pmod{256} = 262 \pmod{256} = 6$ -> символ с кодом `6`
3. **Результат:** строка из символов с полученными кодами

### Процесс дешифрования:
1. Вычитание гаммы с прибавлением модуля:
   * $P_0 = (74 - 9 + 256) \pmod{256} = 65$ → `'A'`
   * $P_1 = (196 - 130 + 256) \pmod{256} = 66$ → `'B'`
   * $P_2 = (6 - 195 + 256) \pmod{256} = 67$ → `'C'`
2. **Результат:** исходный текст `"ABC"`
