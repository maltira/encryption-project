# Документация: Блочный шифр перестановки

## 1. Теоретический базис
Алгоритм разбивает входной текст на блоки фиксированной длины m символов. Порядок символов внутри каждого блока изменяется согласно сгенерированному ключу-перестановке $K = [k_0, k_1, \dots, k_{m-1}]$, где $k_j$ указывает индекс символа из исходного блока, который перемещается на позицию $j$ в шифрограмме

* **Алфавит (V):** Набор разрешенных символов (в текущей конфигурации: русский алфавит `"А..Яа..я"`, 66 символов)
* **Размер блока (m):** Количество символов в одном блоке (в текущей конфигурации: `16`)
* **Мощность пространства ключей:** Количество возможных вариантов перестановок составляет $m!$. Для блока длины `16` число ключей равно $16! \approx 2.09 \times 10^{13}$

---

## 2. API Класса `TranspositionCipher`

Класс реализует интерфейс `Cipher`, инкапсулирует в себе сгенерированный ключ перестановки и методы преобразования строк

### Конструктор
```typescript
new TranspositionCipher(alphabet?: string, blockSize?: number, padSymbol?: string)
```
* `alphabet`: (Опционально) Строка, содержащая разрешенные символы. По умолчанию русский алфавит (строчные и прописные)
* `blockSize`: (Опционально) Число, задающее длину блока $m$. По умолчанию `16`
* `padSymbol`: (Опционально) Символ для дополнения последней группы до кратности размеру блока. По умолчанию `"_"`

### Публичные методы

#### `cleanText(sourceText: string): string`
Удаляет пробельные символы и проверяет, что каждый символ входит в допустимый алфавит `alphabet`.
* **Исключения:** Выбрасывает `Error`, если найден символ, не входящий в алфавит

#### `encrypt(plainText: string): string`
Принимает открытый текст, дополняет его до кратности размеру блока символом `padSymbol`, разбивает на блоки по $m$ символов и переставляет символы каждого блока по правилу `encryptedBlock[j] = block[key[j]]`.

#### `decrypt(cipherText: string): string`
Принимает шифрограмму, проверяет её кратность размеру блока, разбивает на группы по $m$ символов и возвращает каждый символ на исходную позицию: `decryptedBlock[key[j]] = block[j]`.
* **Исключения:** Выбрасывает `Error`, если длина шифрограммы не кратна размеру блока

### Внутренние методы

#### `generateRandomKey(): number[]`
Генерирует случайную перестановку индексов `[0, ..., blockSize - 1]`.
* **Принцип работы:** Создает массив последовательных индексов от `0` до $m - 1$ и перемешивает его с помощью алгоритма **Тасования Фишера - Йетса**, гарантируя равновероятное распределение ключей

## 3. Пример работы алгоритма

Для наглядности рассмотрим блок уменьшенного размера $m = 4$ с ключом $K = [2, 0, 3, 1]$:

```text
Позиция в шифртексте (j) | Индекс из исходного блока (key[j])
-------------------------|-----------------------------------
0                        | 2
1                        | 0
2                        | 3
3                        | 1
```

### Процесс шифрования слова `КРИПТО`:
1. **Препроцессинг (Padding):** Длина слова `КРИПТО` (6 символов) не кратна 4. Строка дополняется символом `_` до длины 8 → `КРИПТО__`
2. **Разбиение на блоки:** Строка разделяется на два блока: `[К, Р, И, П]` и `[Т, О, _, _]`
3. **Перестановка символов:**
   * Блок 1 `[К, Р, И, П]` → `[И, К, П, Р]` (`"ИКПР"`)
   * Блок 2 `[Т, О, _, _]` → `[_, Т, _, О]` (`"_Т_О"`)
4. **Результат:** `ИКПР_Т_О`
