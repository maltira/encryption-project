# Блочный шифр перестановки

## 1. Теория
Алгоритм разбивает входной текст на блоки длины `m` символов. Порядок символов внутри каждого блока (перестановка) изменяется согласно сгенерированному ключу-перестановке $K = [k_0, k_1, \dots, k_{m-1}]$, где $k_j$ указывает индекс символа из исходного блока, который перемещается на позицию $j$ в шифрограмме

* **Алфавит (V):** Набор разрешенных символов (`"А..Яа..я"`)
* **Размер блока (m):** Количество символов в одном блоке (`16`)

---

## 2. API Класса `TranspositionCipher`

### Публичные методы

#### `encrypt(plainText: string, cryptoKey: number | string): string`
Принимает открытый текст и ключ шифрования, строит перестановку `K` по ключу `cryptoKey`, дополняет исходный текст до кратности размеру блока символом `padSymbol`, разбивает на блоки по $m$ символов и переставляет символы каждого блока по правилу `encryptedBlock[j] = block[K[j]]`

* **Требования:** текст должен состоять только из символов алфавита, а ключ быть целым неотрицательным числом

#### `decrypt(cipherText: string, cryptoKey: number | string): string`
Принимает шифрограмму и ключ, проверяет кратность длины шифрограммы размеру блока, строит ту же перестановку `K`, разбивает шифрограмму на группы по $m$ символов и возвращает каждый символ на исходную позицию: `decryptedBlock[K[j]] = block[j]`

* **Исключения:** Выбрасывает `Error`, если длина шифрограммы не кратна размеру блока

### Внутренние методы

#### `generateRandomPositions(cryptoKey: number): void`
Строит перестановку индексов `[0, ..., blockSize - 1]` на основе ключа `cryptoKey` и записывает её в `this.K`

* **Принцип работы:** Берёт массив индексов от `0` до $m - 1$ и перемешивает  его псевдослучайным образом с помощью ключа `key`. Один и тот же ключ всегда даёт одну и ту же перестановку, что позволяет дешифровать текст тем же ключом

## 3. Пример работы алгоритма

Для наглядности рассмотрим блок уменьшенного размера $m = 4$ с ключом $K = [2, 0, 3, 1]$:

```text
Позиция в шифртексте (j) | Индекс из исходного блока (K[j])
-------------------------|----------------------------------------
0                        | 2
1                        | 0
2                        | 3
3                        | 1
```

### Процесс шифрования слова `КРИПТО`:
1. **Padding:** Длина слова `КРИПТО` (6 символов) не кратна 4. Строка дополняется символом `_` до длины 8 -> `КРИПТО__`
2. **Разбиение на блоки:** Строка разделяется на два блока: `[К, Р, И, П]` и `[Т, О, _, _]`
3. **Перестановка символов:**
   * Блок 1 `[К, Р, И, П]` -> `[И, К, П, Р]` (`"ИКПР"`)
   * Блок 2 `[Т, О, _, _]` -> `[_, Т, _, О]` (`"_Т_О"`)
4. **Результат:** `ИКПР_Т_О`
